How I work

The same four steps run through my internships and projects.

Check the data

Clean and validate raw data with SQL, Excel or pandas so the numbers can be trusted before any analysis.

Explore it

Look for patterns, trends and the key business metrics, using EDA, correlation and hypothesis testing where they help.

Build the output

Turn the findings into KPI dashboards in Power BI, Tableau or Excel, or into a tested model in Python.

Explain it

Present results in plain language to non-technical teams, and document the work so others can follow it.
